# Src changelist: notko gets a mockspace

**Date:** 2026-11-19
**Phase:** IMPL
**Round:** 202611192252, the doc changelist `202611192252_changelist.doc.lock.md`, as reopened.

## Changes proposed

No source changes in behaviour. Every change here is a move or a path that follows one.

### CHANGE: move the crates under `mock/crates/`

`notko`, `notko-hlist`, `notko-macros`, `notko-macros-core` and `notko-build` move from the repository
root to `mock/crates/<name>/`, history kept by `git mv`. The workspace manifest becomes
`mock/Cargo.toml`, with the members, the excluded fixture and `[workspace.package]` unchanged; the
crate manifest of `notko` keeps everything else it had.

### CHANGE: the paths that follow the move

- `notko`'s dependency on `notko-macros` and `notko-macros`'s dev-dependency on `notko` name their
  sibling directories, and the consumer fixture of `notko-macros` names `notko` under `crates/`, in its
  manifest and in `consumer_cfg.rs`, which rewrites that path.
- The repository checks among `notko`'s tests read the workspace at `mock/` rather than at the crate:
  `readme_claims.rs` gains `crate_dir` beside `root`, and `every_publishable_crate_can_actually_be_published.rs`
  and `a_probe_crate_says_it_is_a_probe.rs` take the workspace root two levels up.
- `the_seals_hold_from_outside.rs` and `notko-hlist`'s `the_refusals_hold.rs` read the pin at
  `mock/rust-toolchain.toml`.
- `research/` moves to `mock/research/`, and `scripts/feature-matrix.sh` runs from `mock/`.

### CHANGE: the crate readmes are checked as one text

`readme_claims.rs` gains `the_repository_readme_is_this_crate_s_readme`, which fails when the
repository's `README.md` and `mock/crates/notko/README.md` differ. The copies themselves landed in
the doc changelist. The old readmes and licences under the root crate directories go with their crates.

## Verification

The feature matrix runs every arm it ran before the move, with the same counts, before this
changelist locks. Run on 19 November at the move's tip: every arm green, each `notko` arm one test
more than before the move (the readme test this changelist adds, shown failing on a readme made to
differ), every other arm the same count. `cargo mock test`: 289 tests in 42 binaries, all green.

arvo `dev` at `f5bee87f` and hilavitkutin `dev` at `a6e8cb46` were checked against the moved notko at
`a64a507`, every target, with `notko` and `notko-hlist` patched to that commit by git: both green, so
cargo finds both packages in the new layout and nothing downstream reads the old one.

### CHANGE: the fixture of `notko-hlist` is named under an alias

`notko-hlist`'s dev-dependency on its excluded fixture is keyed `carrier-owner`, with `package` naming
the fixture, and `a_carrier_of_another_crate_takes_your_members.rs` imports it under that name. A
dependency key carrying the `notko` prefix is read by mockspace as a workspace member, and drawing the
graph then panics on a fixture that is not one (ticket
`cargo_mock_panics_in_generate_dot_on_a_prefixed_dependency_t`, a FIXME at the site).

### CHANGE: the fixture crates carry a licence

`notko-hlist`'s `tests/carrier_owner/Cargo.toml` and `notko-macros`'s consumer fixture gain
`license = "MPL-2.0"`, the licence of everything here. The
mockspace's push gate runs `cargo deny`, which refuses a crate with no licence, fixture or not.
