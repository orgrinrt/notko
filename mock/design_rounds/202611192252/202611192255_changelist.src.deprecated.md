# Src changelist: notko gets a mockspace

**Date:** 2026-11-19
**Phase:** IMPL
**Round:** 202611192252, the doc changelist `202611192252_changelist.doc.lock.md`.

## Changes proposed

No source changes in behaviour. Every change here is a move or a path that follows one.

### CHANGE: move the crates under `mock/crates/`

`notko`, `notko-hlist`, `notko-macros`, `notko-macros-core` and `notko-build` move from the repository
root to `mock/crates/<name>/`, history kept by `git mv`. The workspace manifest becomes
`mock/Cargo.toml`, with the members, the excluded fixture and `[workspace.package]` unchanged; the
crate manifest of `notko` keeps everything else it had.

### CHANGE: the paths that follow the move

- `notko`'s dependency on `notko-macros` and `notko-macros`'s dev-dependency on `notko` name their
  sibling directories, and the consumer fixture of `notko-macros` names `notko` under `crates/`, in its
  manifest and in `consumer_cfg.rs`, which rewrites that path.
- The repository checks among `notko`'s tests read the workspace at `mock/` rather than at the crate:
  `readme_claims.rs` gains `crate_dir` beside `root`, and `every_publishable_crate_can_actually_be_published.rs`
  and `a_probe_crate_says_it_is_a_probe.rs` take the workspace root two levels up.
- `the_seals_hold_from_outside.rs` and `notko-hlist`'s `the_refusals_hold.rs` read the pin at
  `mock/rust-toolchain.toml`.
- `research/` moves to `mock/research/`, and `scripts/feature-matrix.sh` runs from `mock/`.

### CHANGE: the crate carries its readme

`mock/crates/notko/README.md` and `LICENSE` are copies of the repository's, since a package cannot
reach above itself. `readme_claims.rs` gains `the_repository_readme_is_this_crate_s_readme`, which
fails when the two differ.

## Verification

The feature matrix runs every arm it ran before the move, with the same counts, before this
changelist locks.
