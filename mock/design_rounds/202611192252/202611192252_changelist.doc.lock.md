## The state this starts from

The crates sat at the repository root with the root crate `notko` as the workspace root. No design
template existed anywhere; the readmes and `docs/design/notko-hlist-product-carrier.md` were the only
design prose. With the mock directory in place, `cargo mock` reports six types no design document
names: `Readme` in `notko` and in `notko-hlist`, `Token` in `notko-hlist`, and `Error`, `Source` and
`Origin` in `notko-build`. The documents below name each of them for what it is.

## Reopened

The doc changelist was locked with the crate readmes still at the repository root, and the src
changelist then tried to move them under `mock/crates/`, where a readme is a crate document and moves
only in this window. `202611192255_changelist.src.deprecated.md` is that src changelist, deprecated by
`cargo mock unlock`.

### CHANGE: the crate readmes and licences move under `mock/crates/`

`README.md` and `LICENSE` of `notko-hlist`, `notko-macros`, `notko-macros-core` and `notko-build` move
with their crates, unchanged. `notko`, the root crate, gains `mock/crates/notko/README.md` and
`mock/crates/notko/LICENSE` as copies of the repository's own, since a package cannot reach above
itself; the repository keeps its `README.md` and `LICENSE` at the root as the page a visitor reads. The
old copies under the root crate directories go with the source move in the src changelist, outside the
mock directory.
